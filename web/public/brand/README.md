# Gorila OS brand assets

Diretório reservado para os ativos oficiais da marca.

Contratos previstos:

- `favicon.ico`: favicon multirresolução.
- `icon-192.png`: ícone PWA.
- `icon-512.png`: ícone PWA e instalação.
- `apple-touch-icon.png`: ícone para dispositivos Apple.
- `social-preview.png`: fallback estático para compartilhamento.
- `gorilla-mark.*`: GorillaMark oficial quando aprovada.

Até a entrega da GorillaMark definitiva, a interface utiliza exclusivamente o
`BrandMarkSlot` estrutural. Nenhum monograma temporário deve ser criado.
