# Gorila OS - Official brand assets

This directory is the permanent source of truth for production brand assets.

## Available reference assets

- `brand-book.pdf`: two-page archival PDF generated without visual
  reinterpretation from the approved light and night reference boards.
- `brand-reference-light.jpeg`: untouched approved light reference.
- `brand-reference-night.png`: untouched approved night reference.

## Pending vector source assets

The following production assets must not be reconstructed from the raster
reference boards:

- `gorillamark.svg`
- `gorillamark-dark.svg`
- `gorillamark-light.svg`
- `gorillamark-symbol.svg`
- `gorillamark-horizontal.svg`

To generate them faithfully, provide at least one approved editable vector
source in SVG, AI, EPS or Figma format. The source must preserve the original
paths, gradients, effects, proportions, typography and clear-space rules.

## Pending icon source assets

The reference-board icon specimens are approximately 100 pixels wide. This is
not sufficient to produce a faithful 512-pixel application icon.

The following files therefore remain pending:

- `/favicon.ico`
- `/icon-192.png`
- `/icon-512.png`
- `/apple-touch-icon.png`

Provide the approved icon master as SVG, AI, EPS, Figma or a lossless PNG of at
least 1024 by 1024 pixels.

## Social preview

`/social-preview.png` is an untouched copy of the approved night reference
board. A dedicated social-card master is still recommended if the brand team
requires a specific 1.91:1 composition.
