# PRODUCT ROADMAP

## Visão do Produto

O ConsórcioOS é um Sistema Operacional Inteligente para Consultores de Consórcio.

Seu objetivo é aumentar a produtividade, melhorar a experiência do cliente e auxiliar o consultor durante toda a jornada comercial utilizando automação, inteligência artificial e regras de negócio.

---

# MVP

## Objetivo

Construir um sistema capaz de gerenciar clientes, oportunidades e estratégias comerciais, servindo como base para a IA.

# Ideias Futuras
## 20/07/2026

### Decisão

O ConsórcioOS será desenvolvido como um Sistema Operacional para Consultores de Consórcio e não apenas como um CRM.

### Motivo

O objetivo é apoiar o consultor durante toda a jornada comercial, oferecendo inteligência, automação e recomendações, e não apenas armazenar informações.

### Impacto

Todas as funcionalidades deverão gerar valor para a venda, para a produtividade ou para a experiência do cliente.
- Assistente por voz
- Análise automática de conversas
- IA para geração de propostas
- IA para responder objeções
- Ranking inteligente de oportunidades
